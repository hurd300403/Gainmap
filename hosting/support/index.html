No account required for local use

Gainmap's standard import, editing, and export features work on iPhone and Mac without signing in. An account and eligible Patreon membership are required only when you choose Cloud Sync.

Save an UltraHDR image to Photos

  1. Open a photo or export a session in Gainmap.
  2. Open the share sheet.
  3. Choose Save Image. Gainmap writes the original UltraHDR JPEG bytes so the gain map is preserved.
  4. If asked, allow Gainmap to add images to Photos.

You can also choose Save to Files when you want an ordinary file copy.

Sync or sign-in trouble

  • Confirm the device is online and that you used the same Apple or Google account on each device.
  • Gainmap first checks whether your verified Apple or Google sign-in email matches an active Legacy Lab Patreon membership. If Patreon uses another email, choose Connect Patreon.
  • If the browser uses the wrong Patreon account, choose Try Another Patreon Account. If a membership recently renewed or changed, choose Refresh Status.
  • Leave Gainmap open briefly while large originals finish uploading.
  • If sync remains unavailable, quit and reopen Gainmap, then sign out and back in if necessary.

If an eligible membership becomes inactive, Cloud Sync has a short grace period. Cloud data is retained for a 90-day recovery window from the inactive date, then scheduled for automatic deletion. It is restored if eligibility returns during that window.

Delete your account

In Gainmap on iPhone, open the account menu at the top of the Sessions screen and choose Delete Account. After you authenticate again, Gainmap deletes the account, synced sessions, and private cloud photos, then removes Gainmap’s local copies from that iPhone. Images already exported to Photos or Files are not deleted.
